# 02 · 排版报告如实反映结构状态（空文档 / 无标题 / 正常）

**状态**：ready-for-agent

## What to build

排版完成后，任务页的「排版体检报告」能区分三种结构状态并如实展示：

- **空文档**（0 章 0 正文段）：顶部出现危险级提示「未检测到任何正文内容…」，不再出现「结构识别良好」；
- **有正文无标题**（0 章、有正文段）：出现警告级提示「未识别到章节标题…」并说明两种常见原因；
- **正常**（有章）：维持现状，无告警时仍显示「未发现疑似标题问题，结构识别良好」。

判定由后端完成并随报告落库，前端只负责按评级渲染。

## Blocked by

无

## 验收标准

- **给定**一份只有空白段落的文档，**当**排版完成并打开报告，**那么**显示 `EMPTY` 级告警，且页面上不出现「结构识别良好」。
- **给定**一份有正文但标题全是普通段落（无标题样式、无 1/1.1 编号）的文档，**当**打开报告，**那么**显示 `WARN` 级告警与「未识别到章节标题」文案。
- **给定**一份正常带章节标题的文档，**当**打开报告，**那么** `structureLevel=OK`，无告警条，原有统计与「结构识别良好」照常展示。
- **给定**一条升级前产生的历史任务（`report` JSON 无新字段），**当**打开报告，**那么**按旧行为渲染，不出现任何新告警（兼容不回归）。

## 备注

- 判定只写一处：`FormatReport.evaluateStructure()`；调用点只有 `PaperService` 报告落库前一次。
- 测试接缝：`FormatReport.evaluateStructure()` 纯单测（三组输入）+ 浏览器人工回归一次。
