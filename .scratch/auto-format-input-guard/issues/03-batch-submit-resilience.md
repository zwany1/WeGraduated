# 03 · 批量提交逐篇容错，失败篇目不拖累整批

**状态**：ready-for-agent

## What to build

用户一次选中多篇论文点「批量排版」，其中某篇上传失败时：

- 其余篇目**照常建任务并开始排版**，不需要用户重传；
- 失败的篇目**留在待提交列表**里，成功的篇目移出；
- 结束时给出两条独立提示：成功篇数、失败清单（文件名 + 原因）。

全部失败时不调用建任务接口，只报失败清单。

## Blocked by

无

## 验收标准

- **给定**选中「2 篇正常 + 1 篇 0 字节」，**当**点批量排版，**那么**2 篇正常文档各自产生 `SUCCESS` 任务，界面提示「已提交 2 篇」，并单独提示 1 篇失败及原因。
- **给定**上一场景，**当**批量结束后，**那么**待提交区只剩那 1 篇失败文件（成功的不再重复出现）。
- **给定**只选 1 篇坏文件，**当**点批量排版，**那么**不产生任何任务，仅提示失败原因。
- **给定**全部正常，**当**点批量排版，**那么**行为与现状一致（全部提交、列表清空、提示「已提交 N 篇」）。

## 备注

- 纯前端改动（`FormatTask.vue` 的 `submit()`），无后端接口变更。
- 验收走浏览器（agent-browser）回归；当前前端无单测框架，本轮不引入。
