# 票 06 · 存量数据兼容与降级通道

**status**: pending
**Blocked by**: 01

## What to build

保证改造不抛弃任何既有用户数据，并保证新交互有退路。

1. **存量兼容**：老图只存了结构化配置、没有 DSL 文本。打开时用 `render` 反向生成回填输入框。
   `render` 也失败（配置残缺）时，输入框留空但表单照常可用，**绝不阻断编辑**。
2. **降级通道**：DSL 解析失败或用户不愿写文本时，展开表单仍能完成全部配置，
   生成链路与改造前完全一致。
3. **表单折叠**：所有图的高级字段默认折叠（R6），展开后字段数量与改造前一致。

## 验收标准

1. 给定一张改造前保存、只含结构化配置的图，当加载，那么输入框被 `render` 结果填充，
   且画布渲染结果与改造前一致。

2. 给定一张配置残缺到无法 `render` 的老图，当加载，那么页面不报错、输入框为空、
   表单可正常展开编辑并保存。

3. 给定一段解析失败的 DSL，当点击展开表单，那么可以用表单完成配置并成功生成图。

4. 给定改造前保存的所有图，当逐一加载，那么**没有一张因缺少 DSL 字段而加载失败**。

## 约束

- 存量数据一律不得迁移时改写原配置，只能在读取时按需回填。
