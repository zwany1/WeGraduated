# 02 · 页面视图 / 连续视图 + 真实纸宽 + 页码角标

## What to build

预览工具栏出现「页面 / 连续」切换（默认页面，记住上次选择）。页面视图按文档 `pgSz/pgMar` 渲染真实纸张、页边距、页眉页脚与分页块，每块下方标「第 N 页 / 共 M 页」；连续视图保留整篇滚动但同样使用真实纸宽。工具栏常驻一行说明「分页按文档分页符近似，与 Word 可能有 1 页内偏差」。

## Blocked by

01（断言要先红）。

## 验收标准

- 给定 A4 产物 t320，当在页面视图打开预览，那么 `section` 宽度落在 794±2px，且页与页之间有可见间隔与页码角标。
- 给定 B5 产物（t325），那么 `section` 宽度 ≈ 665±2px，与 A4 明显不同（断言 1 转绿）。
- 给定同一份产物，当切到连续视图，那么不再显示页码角标、正文连续滚动，纸宽仍与页面视图一致。
- 给定页面视图，那么 `section` 数量与文档分页点数同阶（断言 2 转绿），且超长页向下生长而不是裁切文字。
