## 五、发现的问题

### 🟠 问题 1：B5 纸张尺寸不是标准 B5〔已修 ✅〕

- 位置：任务 t336（版式 B · B5-仿宋-1.5 倍）产物 `w:pgSz`
- 现象：写入 `w=8293 h=11810` twips ≈ **146×208mm**，而标准 B5 是 **176×250mm**（也接近 A5 的 148×210mm）
- 影响：选了"B5"却排出接近 A5 的页面，打印/装订规格不对
- 建议：核对 `PageFormatter` 里 B5 的 twips 常量来源
- **已修复**：`PageFormatter` / `PageConfig.pageWidthTwips` 改为 ISO B5 `9978×14173`（176×250mm）。验证：产物 `pgSz=9978x14173`，预览纸宽 665.2px（176mm）

### 🟡 问题 2：预览会多出整张空白页〔已修 ✅〕

- 位置：t335 预览的第 3 页（摘要之后）、第 6 页（目录之后），均为 0 个正文段
- 原因：`sectPr` 节边界处，docx-preview 的 `isPageBreakSection(prev, next)` 在 `pageSize` 有无不一致时多切一次页；Word 里没有这两张白页
- 性质：预览侧遗留缺陷（改造前就存在，与本轮改动无关）
- 影响：页数与成品不一致，「共 N 页」偏大
- **已修复**：渲染后摘掉 `article` 内既无文字、也无图片/表格/公式的 `section`（在编号页码之前执行）。验证：B5 样本 18 页 → **16 页**，摘掉 2 张，页码「第 1 页 / 共 16 页」连续

### 🟡 问题 3：题注编号跟随乱序后的章序，与原稿编号不一致〔已补提示 ✅〕

- 位置：如原稿 `图3-1按钮选型图` → 产物 `图5-1 按钮选型图`
- 说明：S1 把章整体重排后，该图所在的章排到了第 5 位，重新编号是**正确行为**；同时题注编号后补了空格
- 影响：如果用户论文里的图表引用文字（"如图3-1所示"）没有同步更新，会出现交叉引用错位——这是排版引擎的固有风险，建议在报告里提示用户核对
- 不是缺陷，但需要在产品侧给出提示
- **已处理**：`FormatReport` 新增 `renumberedCaptions` / `captionRenumberSamples`，排版体检报告里以告警提示「有 N 个图表题注按新的章节顺序重新编号（图5-1 → 图1-1 …），正文里"如图3-1所示"这类交叉引用不会自动更新，请逐处核对」。顺带修了 `extractCaptionNumbers`：题注写成 `图5-1程序执行流程图`（编号后无空格）时序号被解析成 0

### 🔵 问题 4：预览单页可容纳远超一页的内容

- 位置：t335 预览第 9 页 97 段、第 11 页 121 段
- 原因：浏览器预览不做纵向排版回流，只按分页符/分节切页
- 处理：已在工具栏免责提示中说明「超出一页的内容不会自动接到下一页」，属已知限制

### 🔵 问题 5：差异索引里目录条目类差异占比高

- 现象：对齐 259 条里约 42 条是目录条目（其余是正文「左→两端对齐」，属真实变化）
- 处理：已按类型分组并默认折叠 8 条，用户可展开；不建议隐藏（它们是真差异）
